# NCP 프로젝트 계획서
> New Candlestick Pattern (NCP) — 범용 캔들패턴 전략 개발

---

## 1. 프로젝트 목표

비트코인 1일봉 데이터(BITFINEX_BTCUSD)를 기반으로,  
**비트코인에 과적합되지 않는 범용 캔들패턴**을 발굴하고  
최적의 매매 전략 코드를 작성한다.

---

## 2. 데이터 개요

| 항목 | 내용 |
|------|------|
| 출처 | BITFINEX BTCUSD 1D |
| 컬럼 | time (Unix), open, high, low, close, volume |
| 기간 | 2013-03-31 ~ 2026-03-23 |
| 행 수 | 4,795일 |

---

## 3. 세션 역할 분담

| 세션 | 역할 |
|------|------|
| **NCP1** | 주도 분석 및 코드 작성, 전략 제안 |
| **NCP2** | 검토·반론·대안 제시, 과적합 경고 |
| **NCP3** | 회의록 작성, 논리 일관성 검증, 최종 정리 |

---

## 4. 과적합 방지 원칙

1. **패턴 정의는 가격 비율/형태 기반** — 절대 가격 수준 사용 금지
2. **파라미터 최소화** — 조정 가능한 변수는 3개 이하로 제한
3. **시장 보편성 검토** — NCP2가 각 패턴이 다른 자산(주식, 금, 환율)에서도 유효한지 반론 제기
4. **검증 분리** — 학습(2013~2020) / 검증(2021~2026) 기간 분리
5. **Walk-forward 테스트** — 롤링 윈도우로 시간적 일반화 확인

---

## 5. 개발 단계

### Phase 1: 탐색적 데이터 분석 (EDA)
- [ ] 기초 통계 (수익률 분포, 변동성, 거래량 패턴)
- [ ] 시장 국면 분류 (상승장 / 하락장 / 횡보장)
- [ ] 이상치 및 결측 확인

### Phase 2: 캔들패턴 후보 발굴
- [ ] 기존 고전 패턴 베이스라인 (도지, 해머, 엔걸핑 등)
- [ ] 신규 패턴 후보 아이디어 (NCP1 제안 → NCP2 검토)
- [ ] 패턴 발생 빈도 / 신호 강도 분석

### Phase 3: 전략 설계
- [ ] 진입·청산 규칙 정의
- [ ] 손절·익절 설정 (ATR 기반 권장)
- [ ] 포지션 사이징 (고정 비율 or Kelly)

### Phase 4: 백테스트
- [ ] 학습 구간 백테스트
- [ ] 검증 구간 백테스트
- [ ] Walk-forward 테스트
- [ ] 성과 지표: Sharpe, MDD, Win Rate, Profit Factor

### Phase 5: 검증 및 보고
- [ ] 과적합 지표 점검 (IS vs OOS 성과 괴리)
- [ ] 민감도 분석 (파라미터 ±10% 변화 시 성과 변화)
- [ ] 사용자 최종 검증 요청

## 6. 파일 구조

```
NCP/
├── docs/
│   ├── PROJECT_PLAN.md       ← 이 파일
│   ├── MEETING_LOG.md        ← 회의록 (NCP3 작성)
│   └── VALIDATION_REPORT.md  ← 최종 검증 보고서
├── src/
│   ├── eda.py                ← EDA 스크립트
│   ├── patterns.py           ← 캔들패턴 정의 및 탐지
│   ├── strategy.py           ← 매매 전략 로직
│   └── backtest.py           ← 백테스트 엔진
├── results/
│   └── (백테스트 결과 CSV, 차트)
└── BITFINEX_BTCUSD, 1D.csv
```

## 7. 의사결정 원칙

- NCP1과 NCP2가 **합의하지 못한 사항**은 NCP3가 중재
- 코드 변경 전 **반드시 NCP2의 검토** 거쳐야 함
- 사용자 검증 요청은 **Phase 5 완료 후** NCP1이 직접 보고
