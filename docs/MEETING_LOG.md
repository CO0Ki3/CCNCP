## 회의 #008 — 목표 상향: 월 평균 수익률 30%

**일시:** 2026-05-24  
**참석:** NCP1, NCP2  
**작성:** NCP3

### 결정 사항
- 기존 전략(TailEcho + BearAbsorption) 기반 위에 지속 개발·누적
- **신규 목표: 월 평균 수익률 30%**
- 현재 예상 월 수익률 ~1.9% → 목표 30%로 상향
- NCP1·NCP2 병렬로 개선 방향 탐색 시작

### NCP3 논리 검증 ⚠️

목표 수치에 대해 원칙 관점의 경고를 기록합니다.

- **현실성 격차**: 월 30%는 연환산 약 2,270% 수익률에 해당. 현재 OOS 성과(Sharpe 2.54, 월 ~1.9%) 대비 약 16배 상향으로, 단순 전략 개선으로 달성 가능한 수준을 크게 초과함
- **과적합 위험 증가**: 극단적 수익률 목표를 설정할 경우, 이를 달성하기 위해 IS 구간에 과도하게 최적화된 파라미터나 패턴을 채택할 가능성이 높아짐 → **과적합 방지 원칙과 충돌 가능**
- **레버리지·포지션 사이징 의존 가능성**: 패턴 자체의 edge가 아닌 레버리지로 수익률을 끌어올리는 방향으로 흐를 경우, 이는 프로젝트 원래 목표(범용 캔들패턴 발굴)와 이탈

**NCP3 권고**: 목표를 "절대 수익률"이 아닌 "위험 조정 수익률(Sharpe, PF)" 기준으로 재정의하는 방안을 NCP1·NCP2가 검토할 것을 제안합니다. 사용자 판단에 따라 최종 결정.

## 회의 #007 — DualPressure 재설계 완료 및 최종 전략 확정

**일시:** 2026-05-24  
**참석:** NCP1, NCP2  
**작성:** NCP3

### DualPressure 재설계 경과
- 다수 변형 시도 → 모두 OOS 부진
- **BearAbsorption (하락 흡수)** 으로 재탄생
  - 조건: `t-2` 강한 하락(P75) → `t-1` 강한 상승 + 완전 회복 → Long 진입

### 최종 전략: TailEcho + BearAbsorption 조합

**OOS 성과:**

| 지표 | 값 |
|------|-----|
| 거래 수 | 76건 (연평균 16.4건) |
| 승률 | 51.3% |
| 평균 수익 | +1.37% |
| Sharpe | 2.54 |
| MDD | -22.5% |
| PF | 1.87 |

**Walk-forward:**

| 지표 | 값 |
|------|-----|
| Sharpe | 1.86 |
| PF | 1.56 |

### 결정 사항
- 모든 목표 지표 달성 → 최종 전략 확정
- 사용자 최종 검토 대기

### NCP3 논리 검증

- DualPressure 다수 변형 시도 후 OOS 부진 확인 → 단순 파라미터 조정이 아닌 로직 재탄생 방식으로 과적합 방지 원칙 부합 ✅
- 조합 전략 OOS Sharpe 2.54 / MDD -22.5%: 단일 TailEcho 대비 MDD 개선(-25.2% → -22.5%) ✅
