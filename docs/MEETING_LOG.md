## 회의 #003 — Phase 2 패턴 창안 토론 시작

**일시:** 2026-05-24  
**참석:** NCP1, NCP2 (NCP3 기록)  
**작성:** NCP3

### 안건
1. NCP1 자체 창안 패턴 4종 제안
2. NCP2 검토 및 반론 예정

### NCP1 제안 패턴 (자체 창안)

| ID | 패턴명 | 핵심 아이디어 |
|----|--------|--------------|
| A | **탄성 수렴 (Elastic Convergence)** | 4일 몸통 수렴 후 폭발 |
| B | **꼬리 반향 (Tail Echo)** | 전일 거부된 꼬리 방향 돌파 |
| C | **변동성 단층 (Volatility Fault)** | 극단 변동 후 mean reversion |
| D | **이중 압력 (Dual Pressure)** | 이틀 반대 움직임 후 승자 추종 |

### 창안 근거 (EDA 결과)
- 첨도 17.2 (극단 수익률 빈번 → C, D 패턴 근거)
- 몸통비율 43.2% (꼬리 비중 큼 → B 패턴 근거)
- 국면 분포 (추세·횡보 교차 → A 패턴 근거)

### NCP2 검토 의견
- 수신 대기 중 *(추후 보완 예정)*

### 미결 사항
- NCP2 검토 의견 반영 후 패턴 정의 구체화
- 각 패턴의 수학적 조건 정의 필요

## 회의 #002 — 프로젝트 공식 시작

**일시:** 2026-05-24  
**참석:** NCP1, NCP2, NCP3  
**작성:** NCP3

### 안건
1. 세 세션 역할 공식 확정
2. 프로젝트 공식 시작 선언

### 결정 사항
- **NCP1**: 주도 분석 및 코드 작성 (비트코인 캔들패턴 발굴, 전략 개발)
- **NCP2**: 검토·반론·대안 제시 (NCP1 분석에 대한 비판적 검토)
- **NCP3**: 회의록 작성 및 논리 검증 (결정사항이 과적합 방지 등 프로젝트 원칙에 부합하는지 확인, NCP1·NCP2 합의 불가 시 중재)
- 데이터: BITFINEX_BTCUSD 1일봉 (2013~2026, 4795일)
- GitHub 저장소: https://github.com/CO0Ki3/CCNCP
- 회의록 파일: `docs/MEETING_LOG.md` (NCP3가 관리)

### 프로젝트 원칙 (재확인)
- 학습/검증 기간 분리로 과적합 방지
- 범용 캔들패턴 발굴 목표 (데이터 특이성에 과도하게 맞춘 패턴 지양)

### 미결 사항
- Phase 1 (EDA) 착수 대기

### 추가 원칙 (사용자 지시 — 2026-05-24)
- **패턴 자체 창안 원칙**: 기존 온라인에 알려진 캔들패턴(도지, 해머, 엔걸핑 등)을 참조하거나 변형하는 것이 아닌, NCP1·NCP2·NCP3가 스스로 새로운 패턴을 창안해야 함
- 앞으로 회의록에 패턴 아이디어를 기록할 때 "기존 패턴 변형"이 아닌 "자체 창안"임을 명시
- NCP1 또는 NCP2가 기존 패턴명(도지, 해머 등)을 언급할 경우 회의록에 ⚠️ 경고 표시
- 동일 원칙이 `docs/PROJECT_PLAN.md` 과적합 방지 섹션에도 반영 예정
